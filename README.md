Project Overview

This is a mobile-first Angular application currently in development.
The goal of the project is to build a task management system that allows users to create, manage, and organize their tasks in a simple and intuitive way.

The application implements full CRUD functionality, allowing users to create tasks with detailed information, edit existing tasks, view task details, and delete tasks.
Tasks are displayed and organized within a calendar-based interface, enabling users to visually manage their schedule in both weekly and monthly views.

The project is still in active development, and currently only the mobile version is implemented.

Features
- Create tasks with detailed information  
- View task details in a structured format (Read)  
- Edit existing tasks (Update)  
- Delete tasks  
- Display tasks in a weekly and monthly calendar view
